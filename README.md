# 游戏自动化辅助脚本 (Auto-Farm-Script)

##  项目简介
这是一个基于 Python 编写的个人学习实践项目，主要为了解决游戏内繁琐的重复性日常操作。
由于游戏版本更新，目前项目处于停止开发状态，但核心自动化逻辑已跑通。

## 核心功能
1. 自动收获：模拟操作，实现作物的自动检测与收获。
2. 状态监测：通过基础图像识别/颜色检测技术，实时监测背包容量是否已满。
3. 自动售卖：当检测到背包满时，自动触发售卖逻辑，实现无人值守挂机。

## 技术栈
* 编程语言：Python
* 使用库：基础自动化库、图像处理基础库

## 学习与反思
* 本项目为个人自学探索，通过查阅资料和借助 AI 辅助，掌握了基础自动化流程的设计与实现。
* 在开发过程中尝试了程序的打包与跨设备运行，遇到了环境依赖问题，积累了初步的排查经验。
* 认识到项目维护与版本更新的重要性（游戏更新导致部分功能失效），学会了敏捷评估投入产出比。
